## 📚 Overview

**Data-Structures-and-Algorithms** is a collection of hands-on activities and task performances from a data structures and algorithms course, implemented in both **Python** and **Java**. Each activity folder contains the original instructions (`.txt`) alongside the working source code.

---

## 🚀 What's Inside

- **19 programs** — 10 Python (53%) and 9 Java (47%)
- Data structures covered:
  - Arrays / basic data handling
  - Linked Lists
  - Stacks
  - Queues & Priority Queues
  - Hash Sets & Hash Maps
  - Trees (JTree traversal)
  - Graphs (adjacency lists)
- Algorithms & techniques: recursion (linear/tail), searching, linear traversal
- Course notes PDF and handwritten notes included

## 🏁 Getting Started

### Prerequisites

- [Python 3.8+](https://www.python.org/downloads/)
- [Java JDK 8+](https://adoptium.net/)
- Git (optional, for cloning)

### Running the Code

1. **Clone the repository:**
   ```sh
   git clone https://github.com/sanguirIS/Data-Structures-and-Algorithms.git
   cd Data-Structures-and-Algorithms
   ```

2. **Python files:**
   ```sh
   python <filename>.py
   ```

3. **Java files:**
   ```sh
   javac <FileName>.java
   java <FileName>
   ```
